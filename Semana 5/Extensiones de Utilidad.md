Existen extensiones para el navegador que pueden ayudar durante una prueba de penetración a nivel de software para ahorrar cierto tiempo.

# OWASP Penetration Testing Kit > Wappalyzer
Este sirve para detectar por ejemplo las tecnologías que usa un sitio web este es bueno pero existe uno mejor, que es básicamente un Wappalyzer pero enfocado en pentesting y se llama OWASP Penetration Testing Kit que es una suite pequeña de herramientas para pentesting web ya que además de detectar las potenciales tecnologías que usa un sitio web, nos permite gestionar las cookies, modificar tokens de autentificación, encodear o decodear cadenas de caracteres 

# HackTools
Esta es una compilación mas de herramientas y recursos para agilizar las labores de un pentesting ya que por ejemplo permite generar shell reversas, digamos que tenemos un payload que vamos a inyectar en varios lenguajes de programación, adicionalmente de generar otro tipo de payloads como MSFVenom que forma parte de Metasploit Framework, adicionalmente que también permite consultar CVE y su puntuación CVSS, que son cosas que podríamos hacer de forma manual pero con hacerlas en una extensión podemos ahorrar mas tiempo.

# FoxyProxy
Que esta nos permite configurar de una forma mucho mas rápida y simple cualquier tipo de proxy para que el tráfico del navegador vaya a través de él (del proxy).
